Данные

Пайплайны, витрины и модели данных: что уже работает и что в работе.

готов 2026 Python · PostgreSQL · Docker

ЦБ ETL

Задача Каждый день забирать курсы валют ЦБ РФ, хранить историю и считать по ней витрины. Так, чтобы повторный запуск и догрузка прошлых дней ничего не ломали.

Тесты на pytest. CI в GitHub Actions поднимает PostgreSQL и прогоняет их на каждый push.

Код на GitHub
  1. ИсточникAPI ЦБ РФ
  2. Rawraw_rates, JSONB как пришло
  3. Corerates, строка на дату и валюту
  4. Витриныизменение за день, среднее за 7 дней, волатильность
  5. Проверки6 SQL-проверок, итог в dq_log

  1. Идемпотентность

    Upsert по ключу «дата + валюта»: повторный запуск обновляет строки, а не плодит дубли. Сырой ответ и разобранные строки пишу одной транзакцией.

  2. Бэкфилл

    Флаг --backfill N догружает последние N дней. Упавшая дата не останавливает остальные, но процесс вернёт код 1, чтобы планировщик это увидел.

  3. Проверки качества

    После каждой загрузки: свежесть, пропуски публикаций, скачки курса, смена номинала. Проверка уровня error завершает запуск с ошибкой.
